# 情境便签 · MVP、第二阶段与全屏空间支持

原生 macOS SwiftUI + AppKit 单窗口便签。包含透明无标题栏浮动窗口、便签拖动、窗口缩放及位置尺寸保存、多行文字编辑及自动保存、背景图片与透明度、原生毛玻璃。第二阶段现已加入多个便签 Profile、手动 App 关联、前台 App 驱动的单窗口内容切换，以及轻量的关联建议。

## 构建与运行

需要 macOS 14 或更新版本以及 Swift Command Line Tools。在项目目录运行：

```sh
./scripts/build-app.sh
open outputs/ContextNote.app
```

生成可传输的发布压缩包：

```sh
./scripts/package-release.sh
```

正式包带有版本号、构建号和生产力应用类别；发布脚本会先检查 App 签名，再生成 ZIP 与对应的 SHA-256 校验文件。

鼠标移入便签后，顶部标题和按钮会出现；移开后隐藏。左上角叉号只隐藏窗口，App 会继续在 Dock 中运行；点击 Dock 图标可重新显示，右键 Dock 图标可退出。设置中可以决定是否额外显示菜单栏便签图标；启用后，菜单栏的“显示便签”“设置…”和“退出情境便签”可直接控制 App。也可以按 ⌘Q 真正退出。右上角画笔图标用于设置背景。窗口只从顶部栏使用 macOS 原生方式拖动，右下角缩放柄用于调整尺寸。顶部锁定按钮按 Profile 锁定正文；锁定后正文使用箭头光标且无法误编辑，每行任务完成按钮仍可点击。解锁后单击正文即可编辑，直接拖动可选择文字。文字、背景和窗口位置会自动保存到本机 UserDefaults。

正文中每个非空行的右侧会在鼠标移入便签时显示完成按钮。点击后可将该行划掉，再次点击可取消；也可在齿轮设置的“任务完成后”中选择“直接删除”。划掉状态按 Profile 独立保存，编辑其他行时会继续跟随原来的任务行。

点击右上角齿轮，先添加并选中一个便签，再点“添加 App…”选择 `.app`。关联关系可修改、暂停或删除。切换到关联 App 时，当前窗口显示相应便签；切到未关联 App 时显示“今日总计划”。旧版 MVP 的文字和背景会自动导入默认便签。

在未关联 App 中停留约 3 秒后，会出现“创建关联 / 暂不 / 不再提示”的小提示。建议不会自行创建规则。可在齿轮设置中关闭所有建议；已存在的手动规则不会被建议覆盖。

无 App 关联的非默认便签可以在设置中删除；有 App 关联的便签需先将关联改到其他便签。也可以从应用菜单按 ⌘, 打开便签与 App 关联设置。

浮动便签以菜单栏辅助 App 运行，可显示在其他 App 的全屏空间上方；菜单栏便签图标提供显示、设置和退出操作。在“便签与 App 关联”中可关闭“始终置顶”，使普通桌面窗口可以盖住便签；关闭“在所有桌面显示”，则便签只留在当前普通桌面。各 App 的全屏显示设置仍独立生效。原生全屏和铺满屏幕的最大化窗口都按全屏处理。

General 设置还可以控制菜单栏图标和“登录时自动启动”。登录启动使用 macOS 原生登录项；如果系统要求批准，设置中会显示提示。

外观设置中可在毛玻璃、纯色与已保存的图片间切换。毛玻璃支持浅色与深色样式。切换模式不会删除该 Profile 的背景图片；纯色背景、毛玻璃样式与透明度、背景图片模糊强度、便签圆角和文字颜色模式都按 Profile 保存。文字颜色支持自动、推荐和自定义：自动模式会随背景、亮度与遮罩更新；Smart Palette 会在本机提供四个经过对比度过滤的协调色；自定义模式使用系统颜色选择器。按用户反馈，计划中的“锁定位置”已跳过。

便签内容和 App 关联在每次更新时都会保留上一份内部副本。如果当前本地数据意外损坏，App 下次启动时会自动从内部副本恢复。设置中的 JSON 备份还包含常用行为设置、被忽略的关联建议以及窗口位置和大小，并兼容此前导出的旧版备份。
